# Mohammad Faizan Khan | Personal Portfolio

This is the official portfolio website of **Mohammad Faizan Khan**, a dedicated Project Manager and Operations Specialist. The site showcases professional experience, education, projects, and skills.

## 🚀 Live Demo
Check out the live site here: [mohammad.faizan.khan.linux-aios.com](https://mohammad.faizan.khan.linux-aios.com)

## 🖥️ Technologies Used

- **Framework**: [Next.js](https://nextjs.org/) (React)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **Language**: [TypeScript](https://www.typescriptlang.org)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Backend/Database**: [Firebase](https://firebase.google.com/)
- **Email Service**: [Nodemailer](https://nodemailer.com/)

## 🌟 Key Features

- **Responsive Design**: Optimized for all devices (Desktop, Tablet, and Mobile).
- **SEO Optimized**: Fully integrated with meta tags, sitemap, and robots.txt for better search engine ranking.
- **Dynamic Content**: Powered by Firebase for real-time updates of experience and project data.
- **Contact Form**: Integrated with Nodemailer for direct communication.
- **Multilingual Support**: Arabic and English language support.

## 🛠️ Development Setup

### Step 1 - Install dependencies
```bash
npm install
# or
pnpm install
```

### Step 2 - Run the development server
```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the portfolio.

## 🛑 Important Note

1. **Environment Variables**: Do not push your `.env` or `.env.local` files to GitHub. Ensure `NODEMAILER_PASS` and `NODEMAILER_USER` are kept private.
2. **Firebase Setup**: Ensure your Firebase configuration is correctly set in the environment variables for data fetching to work correctly.
3. **SEO**: Update the google site verification code in `src/data/siteMetaData.mjs`.
